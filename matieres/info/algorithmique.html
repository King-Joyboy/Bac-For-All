Structures de données

Un algorithme manipule des objets déclarés dans le TDOG (Tableau de Déclaration des Objets Globaux) ou le TDOL (Locaux), et des types composés définis dans le TDNT (Tableau de Déclaration des Nouveaux Types).

Tableau 1D (Vecteur)Tab = Tableau de N Entiers (indices 0 à N-1)Collection homogène de taille fixe : accès T[i].
Tableau 2D (Matrice)Mat = Tableau de L × C RéelsGrille à L lignes et C colonnes : accès M[i, j].

Sous-programmes & passage de paramètres

⚙️ Fonction

Retourne un seul résultat de type simple (ou chaîne) via Retourner valeur. Appelée dans une expression ou une affectation.

🛠️ Procédure

Exécute une action : affichage, remplissage, tri, ou modification de plusieurs résultats. Appelée directement par son nom.

Passage de paramètres
  • Par valeur (sans @) : le paramètre effectif n'est pas modifié à la sortie du module.
  • Par variable (noté @) : toute modification dans le module affecte directement la variable d'origine.

Fonctions prédéfinies sur les chaînes et caractères

Fonction / ProcédureRôle et exemple

Algorithmes de recherche

Recherche séquentielle (tableau quelconque)

Parcourt le tableau élément par élément jusqu'à trouver x ou atteindre la fin.

Fonction Rech_Seq(T : Tab ; n, x : Entier) : Booléen
Début
    i ← 0 ; trouve ← Faux
    Tant Que (i < n) et (Non trouve) Faire
        Si T[i] = x Alors trouve ← Vrai
        Sinon i ← i + 1
        Fin Si
    Fin Tant Que
    Retourner trouve
Fin

Recherche dichotomique (tableau obligatoirement trié croissant)

Divise l'intervalle de recherche par deux à chaque itération. Complexité très efficace : \(O(\log_2 n)\).

Fonction Rech_Dicho(T : Tab ; n, x : Entier) : Booléen
Début
    g ← 0 ; d ← n - 1 ; trouve ← Faux
    Tant Que (g ≤ d) et (Non trouve) Faire
        m ← (g + d) Div 2
        Si T[m] = x Alors trouve ← Vrai
        Sinon Si x < T[m] Alors d ← m - 1
        Sinon g ← m + 1
        Fin Si
    Fin Tant Que
    Retourner trouve
Fin

Algorithmes de tri (ordre croissant)

Tri par sélection

À chaque étape i, on cherche l'indice du minimum dans le sous-tableau [i .. n-1] puis on le permute avec T[i].

Procédure Tri_Selection(@T : Tab ; n : Entier)
Début
    Pour i de 0 à n - 2 Faire
        imin ← i
        Pour j de i + 1 à n - 1 Faire
            Si T[j] < T[imin] Alors imin ← j Fin Si
        Fin Pour
        Si imin ≠ i Alors
            aux ← T[i] ; T[i] ← T[imin] ; T[imin] ← aux
        Fin Si
    Fin Pour
Fin

Tri à bulles

Compare deux éléments adjacents et les permute s'ils sont mal ordonnés. On s'arrête dès qu'un parcours s'effectue sans aucune permutation.

Procédure Tri_Bulles(@T : Tab ; n : Entier)
Début
    Répéter
        echange ← Faux
        Pour i de 0 à n - 2 Faire
            Si T[i] > T[i + 1] Alors
                aux ← T[i] ; T[i] ← T[i + 1] ; T[i + 1] ← aux
                echange ← Vrai
            Fin Si
        Fin Pour
        n ← n - 1
    Jusqu'à (Non echange) ou (n = 1)
Fin

Tri par insertion

Insère chaque élément T[i] à sa place correcte dans la partie déjà triée [0 .. i-1] en décalant les éléments plus grands vers la droite.

Procédure Tri_Insertion(@T : Tab ; n : Entier)
Début
    Pour i de 1 à n - 1 Faire
        tmp ← T[i] ; j ← i
        Tant Que (j > 0) et (T[j - 1] > tmp) Faire
            T[j] ← T[j - 1]
            j ← j - 1
        Fin Tant Que
        T[j] ← tmp
    Fin Pour
Fin

Tri Shell

Amélioration du tri par insertion utilisant un pas décroissant p (initialisé par p ← 3 * p + 1 tant que p < n, puis réduit par p ← p Div 3).

Procédure Tri_Shell(@T : Tab ; n : Entier)
Début
    p ← 1
    Tant Que p < n Faire p ← 3 * p + 1 Fin Tant Que
    Tant Que p > 1 Faire
        p ← p Div 3
        Pour i de p à n - 1 Faire
            tmp ← T[i] ; j ← i
            Tant Que (j ≥ p) et (T[j - p] > tmp) Faire
                T[j] ← T[j - p]
                j ← j - p
            Fin Tant Que
            T[j] ← tmp
        Fin Pour
    Fin Tant Que
Fin

La récursivité

Un sous-programme est récursif s'il s'appelle lui-même. Pour éviter une boucle infinie, il doit obligatoirement comporter :

🛑 Condition d'arrêt (cas de base)

Renvoie directement un résultat sans appel récursif.

🔁 Cas général

Appelle le module sur un problème de taille strictement plus petite qui converge vers le cas de base.

Problème classiqueDéfinition récursive
Factorielle Fact(n)Si n = 0 Alors Retourner 1 Sinon Retourner n * Fact(n - 1)
Puissance Puiss(x, n)Si n = 0 Alors Retourner 1 Sinon Retourner x * Puiss(x, n - 1)
PGCD (Euclide)Si b = 0 Alors Retourner a Sinon Retourner PGCD(b, a Mod b)
Palindrome Pal(ch)Si Long(ch) ≤ 1 Alors Vrai Sinon Si ch[0] ≠ ch[Long(ch)-1] Alors Faux Sinon Pal(Sous_chaîne(ch, 1, Long(ch)-1))
Somme tableau Som(T, n)Si n = 0 Alors Retourner 0 Sinon Retourner T[n - 1] + Som(T, n - 1)

Algorithmes arithmétiques et d'approximation

🔢 Test de primalité

Un entier \(n > 1\) est premier s'il n'a aucun diviseur dans \([2 \dots \operatorname{Ent}(\sqrt{n})]\) (ou n Div 2).

🔄 Conversion Décimal → Base b

Divisions euclidiennes successives par b ; on concatène les restes (convertis en chiffres 0..9 ou lettres A..F) par la gauche jusqu'à ce que le quotient soit nul.

🎯 Dichotomie pour \(f(x) = 0\)

Sur \([a, b]\) avec précision eps : tant que \((b - a) > \text{eps}\) et \(f(m) \neq 0\), poser \(m \leftarrow (a+b)/2\) ; si \(f(a)\times f(m) < 0\) alors \(b \leftarrow m\) sinon \(a \leftarrow m\).

📐 Calcul approché d'intégrale

Sur \([a, b]\), \(n\) subdivisions, pas \(h = \dfrac{b-a}{n}\) :

  • Rectangles (gauche) : \(S \leftarrow \sum_{i=0}^{n-1} f(a + i\cdot h)\), résultat \(h\cdot S\).
  • Trapèzes : \(S \leftarrow \dfrac{f(a)+f(b)}{2} + \sum_{i=1}^{n-1} f(a + i\cdot h)\), résultat \(h\cdot S\).

Méthode & astuces Bac

Réflexes indispensables le jour de l'examen
  • Vérifie toujours les conditions de saisie avec une boucle Répéter ... Jusqu'à.
  • Déclare tous les objets utilisés dans les tableaux TDOG / TDOL avec leurs types exacts (sans oublier les variables de boucle et auxiliaires).
  • Ferme systématiquement chaque fichier ouvert (Fermer(F)) avant de quitter le sous-programme.
  • Vérifie le passage par variable @ pour tout paramètre modifié dans une procédure.
