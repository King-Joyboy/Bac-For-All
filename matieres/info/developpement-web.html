HTML5 : structure sémantique et formulaires

HTML5 définit la structure logique d'une page web avec des balises sémantiques (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>) et collecte les données utilisateur via <form>.

<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Inscription</title>
    <link rel="stylesheet" href="style.css">
    <script src="controle.js"></script>
</head>
<body>
    <form name="f" action="ajout.php" method="post" onsubmit="return verif()">
        <fieldset>
            <legend>Coordonnées</legend>
            <label for="nom">Nom :</label>
            <input type="text" id="nom" name="nom" placeholder="Votre nom">

            <label>Genre :</label>
            <input type="radio" name="genre" id="h" value="H"> Homme
            <input type="radio" name="genre" id="f" value="F"> Femme

            <label for="ville">Ville :</label>
            <select id="ville" name="ville">
                <option value="0">-- Choisir --</option>
                <option value="Tunis">Tunis</option>
                <option value="Nabeul">Nabeul</option>
            </select>

            <input type="checkbox" id="cond" name="cond"> J'accepte les conditions
            <input type="submit" value="Valider">
            <input type="reset" value="Annuler">
        </fieldset>
    </form>
</body>
</html>

Autres balises fréquentes au Bac

  • Navigation & cadres : <a href="page.html" target="cadre">Lien</a> avec <iframe name="cadre" src="accueil.html"></iframe>.
  • Tableaux : <table>, <tr> (ligne), <th> (en-tête), <td> (cellule), colspan / rowspan.
  • Médias : <img src="img.jpg" alt="description">, <audio controls src="...">, <video controls src="...">.

JavaScript : DOM et fonctions usuelles

JavaScript s'exécute côté client dans le navigateur pour rendre la page interactive et valider les champs d'un formulaire avant son envoi au serveur.

Instruction JavaScriptRôle
document.getElementById("id").valueLit ou modifie le texte d'un champ (input, select, textarea).
document.getElementById("id").checkedRetourne true si un bouton radio ou une checkbox est coché(e).
document.getElementById("id").selectedIndexIndice de l'option sélectionnée dans un <select> (0 par défaut).
document.getElementById("id").innerHTMLLit ou modifie le contenu HTML affiché dans une balise (<p>, <div>).
ch.length / ch.charAt(i) / ch.indexOf(s)Longueur / caractère à l'indice i / 1ère position de s (-1 si absent).
ch.substring(d, f) / ch.toUpperCase()Sous-chaîne de d à f-1 / conversion en majuscules.
isNaN(x) / Number(ch) / parseInt(ch)Vérifie si x n'est pas un nombre / conversion chaîne → nombre ou entier.
new Date()Date système : .getFullYear(), .getMonth() + 1 (mois de 0 à 11), .getDate().

Script type de validation de formulaire

function estAlpha(ch) {
    ch = ch.toUpperCase();
    for (let i = 0; i < ch.length; i++) {
        let c = ch.charAt(i);
        if ((c < "A" || c > "Z") && c != " ") return false;
    }
    return true;
}

function verif() {
    let nom   = document.getElementById("nom").value.trim();
    let h     = document.getElementById("h").checked;
    let f     = document.getElementById("f").checked;
    let ville = document.getElementById("ville").selectedIndex;
    let cond  = document.getElementById("cond").checked;

    if (nom == "" || !estAlpha(nom)) {
        alert("Nom invalide (lettres uniquement) !");
        return false;
    }
    if (!h && !f) {
        alert("Veuillez choisir votre genre !");
        return false;
    }
    if (ville == 0) {
        alert("Veuillez sélectionner une ville !");
        return false;
    }
    if (!cond) {
        alert("Vous devez accepter les conditions !");
        return false;
    }
    return true;
}

PHP & MySQL : traitement côté serveur

PHP s'exécute sur le serveur web entre <?php et ?>. Les variables commencent toujours par $, la concaténation utilise le point ., et les données du formulaire arrivent dans $_POST["name"] (ou $_GET["name"]).

<?php
// 1. Connexion à la base de données MySQL
$cnx = mysqli_connect("localhost", "root", "", "bd_commerce")
       or die("Erreur de connexion : " . mysqli_connect_error());

// 2. Récupération des données du formulaire (attribut name="...")
$nom   = $_POST["nom"];
$genre = $_POST["genre"];
$ville = $_POST["ville"];
$dt    = date("Y-m-d");

// 3. Vérifier l'existence avant d'insérer (SELECT)
$req1 = "SELECT * FROM Client WHERE nom = '$nom'";
$res1 = mysqli_query($cnx, $req1);
if (mysqli_num_rows($res1) > 0) {
    echo "<p>Ce client existe déjà !</p>";
} else {
    // 4. Insertion (INSERT)
    $req2 = "INSERT INTO Client (nom, genre, ville, dateInsc)
             VALUES ('$nom', '$genre', '$ville', '$dt')";
    mysqli_query($cnx, $req2);
    if (mysqli_affected_rows($cnx) > 0) {
        echo "<p>Inscription réussie !</p>";
    }
}

// 5. Affichage d'une table HTML à partir d'un SELECT
$res = mysqli_query($cnx, "SELECT nom, ville FROM Client ORDER BY nom");
echo "<table border='1'><tr><th>Nom</th><th>Ville</th></tr>";
while ($t = mysqli_fetch_array($res)) {
    echo "<tr><td>" . $t["nom"] . "</td><td>" . $t["ville"] . "</td></tr>";
}
echo "</table>";

// 6. Fermeture de la connexion
mysqli_close($cnx);
?>

Fonctions PHP / MySQL indispensables

Fonction PHPUtilité
isset($_POST["x"])Vérifie qu'un champ (ou une case à cocher) a bien été envoyé.
date("Y-m-d") / date("H:i:s")Date système au format SQL (AAAA-MM-JJ) / heure courante.
mysqli_num_rows($res)Nombre de lignes retournées par une requête SELECT.
mysqli_fetch_array($res)Extrait la ligne suivante (accès par $t[0] ou $t["colonne"]).
mysqli_affected_rows($cnx)Nombre de lignes affectées par INSERT, UPDATE ou DELETE.

Pièges classiques en Développement Web (Bac)

À vérifier avant de rendre ta copie
  1. En JavaScript, on cible les champs avec id (getElementById) ; en PHP, on récupère les valeurs avec name ($_POST["name"]).
  2. N'oublie jamais le mot-clé return dans onsubmit="return verif()", sinon le formulaire est soumis même si verif() renvoie false.
  3. Pour les boutons radio d'un même choix, donne-leur le même attribut name mais des id et value différents.
