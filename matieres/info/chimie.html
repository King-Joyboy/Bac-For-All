⚗️ Chimie

Formules essentielles, tableaux d&#x27;avancement, équilibres, pH, piles électrochimiques et chimie organique.

Cinétique chimique

Pour une réaction chimique d'équation : \(a\,\text{A} + b\,\text{B} \longrightarrow c\,\text{C} + d\,\text{D}\).

Avancement \(x(t)\) (mol)$$n(\text{A}) = n_0(\text{A}) - ax \;;\; n(\text{C}) = n_0(\text{C}) + cx$$
Vitesse instantanée$$v(t) = \frac{dx}{dt} \quad (\text{mol}\cdot\text{s}^{-1})$$
Vitesse volumique$$v_{\text{vol}}(t) = \frac{1}{V}\frac{dx}{dt} \quad (\text{mol}\cdot\text{L}^{-1}\cdot\text{s}^{-1})$$
Temps de demi-réaction \(t_{1/2}\)$$x(t_{1/2}) = \frac{x_f}{2}$$

Graphiquement : \(v(t_1)\) est le coefficient directeur (la pente) de la tangente à la courbe \(x = f(t)\) à l'instant \(t_1\).

Facteurs cinétiques

🌡️ Température

Plus \(T\) augmente, plus la vitesse augmente (et \(t_{1/2}\) diminue).

🧪 Concentration initiale

Plus la concentration initiale des réactifs est grande, plus la réaction est rapide.

⚡ Catalyseur

Accélère la réaction sans être consommé et sans modifier l'état final (\(x_f\) inchangé).

Équilibre chimique et loi d'action de masse

Pour un système siège d'une réaction limitée : \(a\,\text{A} + b\,\text{B} \rightleftharpoons c\,\text{C} + d\,\text{D}\).

Taux d'avancement final$$\tau_f = \frac{x_f}{x_{\max}} \quad (0 < \tau_f \le 1)$$
Fonction des concentrations \(\Pi\)$$\Pi = \frac{[\text{C}]^c \cdot [\text{D}]^d}{[\text{A}]^a \cdot [\text{B}]^b}$$
  • Si \(\tau_f = 1\) (\(x_f = x_{\max}\)) : réaction totale. Si \(\tau_f < 1\) (\(x_f < x_{\max}\)) : réaction limitée (équilibre dynamique).
  • Constante d'équilibre \(K\) : à l'équilibre dynamique, \(\Pi_{\text{éq}} = K\). Elle ne dépend que de la température.
Attention à \(\Pi\) Les solides et le solvant (l'eau en solution aqueuse) n'apparaissent jamais dans \(\Pi\) (leur activité vaut \(1\)).

Sens d'évolution spontanée & lois de modération

  • \(\Pi < K\) : évolution dans le sens direct (sens 1).
  • \(\Pi > K\) : évolution dans le sens inverse (sens 2).
  • \(\Pi = K\) : le système est à l'équilibre.
  • Température : une augmentation de \(T\) déplace l'équilibre dans le sens endothermique.
  • Pression (gaz) : une augmentation de \(P\) déplace l'équilibre dans le sens qui diminue le nombre de moles de gaz.

Acides, bases et pH des solutions aqueuses

Produit ionique de l'eau (25 °C)$$K_e = [\text{H}_3\text{O}^+][\text{OH}^-] = 10^{-14} \;;\; pK_e = 14$$
Définition du pH$$\text{pH} = -\log[\text{H}_3\text{O}^+] \iff [\text{H}_3\text{O}^+] = 10^{-\text{pH}}$$
Constante d'acidité \(K_a\) (\(\text{AH}/\text{A}^-\))$$K_a = \frac{[\text{A}^-][\text{H}_3\text{O}^+]}{[\text{AH}]} \;;\; \text{pH} = pK_a + \log\frac{[\text{A}^-]}{[\text{AH}]}$$
Type de solutionRelation de pH (à 25 °C)Remarque / Dilution
Acide fort (\(\tau_f = 1\))\(\text{pH} = -\log C_a\)Dilution par 10 ⟹ le pH augmente de 1.
Base forte (\(\tau_f = 1\))\(\text{pH} = 14 + \log C_b\)Dilution par 10 ⟹ le pH diminue de 1.
Acide faible (\(\tau_f < 1\))\(\text{pH} = \tfrac12(pK_a - \log C_a)\)Valable si faiblement ionisé (\(\tau_f \le 0{,}05\)).
Base faible (\(\tau_f < 1\))\(\text{pH} = 7 + \tfrac12(pK_a + \log C_b)\)Valable si faiblement ionisée.

Dosage acido-basique

  • À l'équivalence (E) : \(C_a V_a = C_b V_{bE}\).
  • Acide fort + Base forte ⟹ \(\text{pH}_E = 7\).
  • Acide faible + Base forte ⟹ \(\text{pH}_E > 7\) (milieu basique).
  • Base faible + Acide fort ⟹ \(\text{pH}_E < 7\) (milieu acide).
  • À la demi-équivalence (\(V_b = V_{bE}/2\), acide faible dosé par base forte) : \([\text{AH}] = [\text{A}^-] \implies \text{pH} = pK_a\) (solution tampon).

Les piles électrochimiques

Symbole : \(\text{M}_1 \mid \text{M}_1^{n_1+}(C_1) \;\|\; \text{M}_2^{n_2+}(C_2) \mid \text{M}_2\). Équation associée : \(n_2\text{M}_1 + n_1\text{M}_2^{n_2+} \rightleftharpoons n_2\text{M}_1^{n_1+} + n_1\text{M}_2\) (\(n = n_1 n_2\) électrons échangés).

Force électromotrice (f.é.m.)$$E = V_{\text{droite}} - V_{\text{gauche}} = E^\circ - \frac{0{,}06}{n}\log\Pi, \quad \Pi = \frac{[\text{M}_1^{n_1+}]^{n_2}}{[\text{M}_2^{n_2+}]^{n_1}}$$
f.é.m. standard & pile usée (\(E=0\))$$E^\circ = E^\circ(\text{M}_2^{n_2+}/\text{M}_2) - E^\circ(\text{M}_1^{n_1+}/\text{M}_1) \;;\; K = 10^{\frac{n E^\circ}{0{,}06}}$$
  • Si \(E > 0\) : électrode de droite = pôle \(+\) (cathode, réduction) ; électrode de gauche = pôle \(-\) (anode, oxydation). Réaction spontanée dans le sens direct.
  • Si \(E < 0\) : polarités inversées ; réaction spontanée dans le sens inverse.

Chimie organique : alcools et estérification

  • Classes d'alcools (\(\text{R}-\text{OH}\)) : primaire (carbone fonctionnel lié à 0 ou 1 carbone), secondaire (lié à 2 carbones), tertiaire (lié à 3 carbones).
  • Oxydation ménagée :
    • Alcool primaire \(\xrightarrow{[\text{O}]}\) Aldéhyde \(\xrightarrow{[\text{O}]\text{ excès}}\) Acide carboxylique.
    • Alcool secondaire \(\xrightarrow{[\text{O}]}\) Cétone.
    • Alcool tertiaire : ne subit pas d'oxydation ménagée.
Estérification et hydrolyse$$\text{Acide carboxylique} + \text{Alcool} \rightleftharpoons \text{Ester} + \text{Eau}$$
Caractéristiques & rendements (mélange initial équimolaire) Réaction lente, limitée et athermique (la température accélère la réaction sans modifier le rendement \(r\)).
Alcool primaire : \(r \approx 67\%\)  |  Alcool secondaire : \(r \approx 60\%\)  |  Alcool tertiaire : \(r \approx 5\%\).
