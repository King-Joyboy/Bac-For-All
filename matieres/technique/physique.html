Oscillations Électriques Libres & Forcées (RLC)

  • Circuit LC idéal (non amorti) : d²uC/dt² + ω0² uC = 0 avec ω0 = 1/√(LC) , période propre T0 = 2π√(LC) , énergie totale E = Ee + Em = cte .
  • Circuit RLC amorti : Régime pseudo-périodique ( Rt faible, T ≈ T0 ) ou apériodique ( Rt grande). Dissipation : dE/dt = −Rt i² ≤ 0 .
  • RLC en régime sinusoïdal forcé :
Impédance : Z = U/I = √[Rt² + (Lω − 1/(Cω))²] | Déphasage (Δϕ = ϕu − ϕi) : cos(Δϕ) = Rt/Z ;
tan(Δϕ) = (Lω − 1/Cω)/Rt Résonance d'intensité (N = N0) : Lω0 = 1/(Cω0) ⇒ Zmin = Rt, Imax = U/Rt, Δϕ = 0.
Facteur de qualité : Q = Lω0/Rt = UC/U (surtension si Q > 1). | Puissance moyenne : P = U I
cos(Δϕ) = Rt I².

Filtres Électriques

  • Transmittance : T = Us / Ue ; Gain (dB) : G = 20 log(T) .
  • Bande passante à −3 dB : T ≥ T0 / √2 (soit G ≥ Gmax − 3 dB ).
  • Passe-bas (RC sur C) : Nc = 1/(2πRC) , passe N ≤ Nc . Passe-haut (RC sur R) : passe N ≥ Nc .
  • Passe-bande (RLC sur R) : T0 = R/(R+r) ; largeur de bande ΔN = N2 − N1 = Rt/(2πL) = N0/Q .

Oscillations Mécaniques (Pendule Élastique)

  • Équation différentielle (non amorti) : m · d²x/dt² + k · x = 0 ⇒ ω0 = √(k/m) , T0 = 2π√(m/k) .
  • Énergie mécanique : Em = Ec + Epe = ½ m v² + ½ k x² (constante sans frottements).
  • Amorti (frottement visqueux f = −h v) : m x'' + h x' + k x = 0 ; dEm/dt = −h v² ≤ 0 .
  • Forcé (excitateur sinusoïdal Fm sin(ωt)) : Analogie électromécanique : m ↔ L , h ↔ R , k ↔ 1/C , x ↔ q , v ↔ i , F ↔ u .

Ondes Mécaniques Progressives

  • Célérité : v = d/Δt = λ · N = λ / T (corde tendue : v = √(F/μ) ).
  • Équation horaire d'un point M à distance x de S : Pour t ≥ θ = x/v , yM(t) = a sin(2πt/T − 2πx/λ + ϕS) (et 0 pour t < θ ).
  • Points en phase : x = kλ . En opposition de phase : x = (2k+1)λ/2 .

Physique Atomique & Nucléaire

  • Atome d'hydrogène : En = −13,6 / n² (en eV, 1 eV = 1,6×10−19 J). Transition : ΔE = |Ep − En| = h · ν = h · c / λ .
  • Radioactivité : Lois de Soddy (conservation de A et Z). Types : α (4
  • 2He), β− (0 −1e), β+ (0
  • +1e), γ (désexcitation).
  • Décroissance radioactive : N(t) = N0 e−λt ; activité A(t) = λ N(t) (Bq) ; demi-vie T = ln(2) / λ .
  • Énergie de liaison : El = Δm · c² = [Z mp + (A−Z) mn − m(X)] c² . Plus El/A est grand, plus le noyau est stable.
