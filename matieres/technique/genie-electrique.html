Logique Combinatoire & Séquentielle

  • Algèbre de Boole & De Morgan : !(A · B) = !A + !B et !(A + B) = !A · !B . Simplification par tableau de Karnaugh (regroupements de 2n cases adjacentes : 1, 2, 4, 8...).
  • Circuits combinatoires : Multiplexeur (sélectionne 1 entrée parmi 2n), Décodeur (ex : BCD → 7 segments), Comparateur, Additionneur.
  • Bascules (Logique séquentielle) :
  • Bascule D : Recopie D sur front actif d'horloge (Q+ = D).
  • Bascule JK : J=0, K=0 (mémoire) ; J=0, K=1 (RAZ : 0) ; J=1, K=0 (Mise à 1) ; J=1, K=1 (basculement / toggle : Q+ = !Q).
  • Compteurs : Modulo N (compte de 0 à N−1). Nombre de bascules nécessaires : 2n−1 < N ≤ 2n . Fréquence de sortie : fs = fH / N .

GRAFCET (Norme IEC 60848)

  • 3 niveaux : Point de vue Système (cahier des charges), Point de vue Partie Opérative (actionneurs/capteurs), Point de vue Partie Commande (pré-actionneurs KM1, Distributeurs 14M1, entrées API/PIC).
  • Règles d'évolution : Une transition est franchie si toutes les étapes immédiatement précédentes sont actives ET la réceptivité associée est vraie. Le franchissement désactive les étapes précédentes et active les suivantes simultanément.
  • Structures : Séquence unique, Divergence/Convergence en OU (aiguillage, choix exclusif), Divergence/Convergence en ET (séquences simultanées, double barre).
  • Équations d'activation/désactivation d'une étape Xi : Xi = (CAi + Xi) · !CDi (mise en équation pour câblage ou programmation).

Microcontrôleur PIC (16F84A / 16F877)

  • Configuration des ports : Registre TRISA / TRISB ( 1 = Entrée, 0 = Sortie). Lecture/Écriture via PORTA / PORTB .
  • Conversion Analogique-Numérique (CAN 10 bits sur PIC16F877) :
Quantum (pas de quantification) : q = Vref / (2n − 1) (pour n = 10 bits, 210−1 = 1023)
Valeur numérique : N = Vin / q
  • Programmation MikroC : TRISB = 0x00; (PORTB en sortie), PORTB.F0 = 1; , Delay_ms(500); , ADC_Read(0); .

Courant Alternatif Monophasé & Triphasé

  • Monophasé : P = U · I · cos(ϕ) (W), Q = U · I · sin(ϕ) (var), S = U · I = √(P² + Q²) (VA), cos(ϕ) = P / S .
  • Réseau triphasé équilibré : Tension simple V (phase-neutre), tension composée U = V · √3 (entre phases).
CouplageTension par enroulementCourant en ligne IChoix sur plaque signalétique (ex: 230V/400V)
Étoile (Y)V = U / √3I = JSi Uréseau = plus grande tension (400V)

  • Puissances en triphasé (Y ou Δ) : P = √3 · U · I · cos(ϕ) ; Q = √3 · U · I · sin(ϕ) ; S = √3 · U · I .
  • Théorème de Boucherot : Ptot = Σ Pi et Qtot = Σ Qi (jamais additionner les S directement !).
  • Relèvement du facteur de puissance : Pour passer de cos(ϕ) à cos(ϕ') :
Capacité par phase (en Δ) : CΔ = P · (tan ϕ − tan ϕ') / (3 · ω · U²) | En étoile : CY = 3 · CΔ

Moteur Asynchrone Triphasé (MAS)

Vitesse de synchronisme : ns = 60 · f / p (tr/min, p = nb de paires de pôles)
Glissement : g = (ns − n) / ns | Couple utile : Tu = Pu / ω = Pu / (2πn/60)
  • Bilan des puissances : Pa = √3 U I cos(ϕ) → pertes Joule stator ( Pjs = 3/2 R I² ) & pertes fer stator ( Pfs ) → Puissance transmise au rotor Ptr = Pa − Pjs − Pfs → pertes Joule rotor Pjr = g · Ptr → pertes mécaniques Pm → Puissance utile Pu = Ptr − Pjr − Pm .
  • Rendement : η = Pu / Pa . Couple électromagnétique : Tem = Ptr / ωs .
  • Inversion du sens de rotation : Permuter deux phases d'alimentation.

Électronique de Puissance & Analogique

  • Redressement commandé / non commandé (Pont de Graetz PD2) : Tension moyenne Umoy = 2 Umax / π (double alternance).
  • Hacheur série (commande moteur CC) : Umoy = α · E avec α = ton / T (rapport cyclique, 0 ≤ α ≤ 1 ). Vitesse du MCC proportionnelle à Umoy .
  • Amplificateur Opérationnel (AO idéal) :
  • Régime linéaire (contre-réaction sur l'entrée −) : ε = V+ − V− = 0 , i+ = i− = 0 . Suiveur : Vs = Ve . Inverseur : Vs = −(R2/R1) Ve . Non-inverseur : Vs = (1 + R2/R1) Ve .
  • Régime saturé (comparateur) : Si V+ > V− ⇒ Vs = +Vsat ; si V+ < V− ⇒ Vs = −Vsat .
