🎲 Mathématiques : Algèbre, Espace & Proba

4ème Sciences Techniques (Tunisie) • Nombres Complexes, Géométrie dans l'Espace &Probabilités

Nombres Complexes

  • Formes d'un complexe z = a + ib :
  • Module : |z| = √(a² + b²) . Argument : cos(θ) = a/|z| , sin(θ) = b/|z| .
  • Forme trigonométrique / exponentielle : z = r(cos θ + i sin θ) = r · eiθ .
  • Formules de Moivre & Euler :
Moivre : (eiθ)n = einθ | Euler : cos(θ) = (eiθ + e−iθ)/2 ; sin(θ) = (eiθ − e−iθ)/(2i)
  • Équation du 2nd degré a z² + b z + c = 0 : Calculer Δ = b² − 4ac . Chercher une racine carrée δ de Δ (si Δ < 0 , δ = i√|Δ| ), puis z1,2 = (−b ± δ)/(2a) .
  • Racines n-ièmes de Z = r eiα : zk = r1/n · ei(α + 2kπ)/n pour k ∈ {0, 1, ..., n−1} .
  • Interprétation géométrique :
  • AB = |zB − zA| | Angle (AB, AC) ≡ arg((zC − zA)/(zB − zA)) [2π] .
  • A, B, C alignés ⇔ (zC−zA)/(zB−zA) ∈ ℝ.
  • (AB) ⊥ (AC) ⇔ (zC−zA)/(zB−zA) ∈ iℝ* (imaginaire pur).

Géométrie dans l'Espace

  • Produit scalaire : u · v = xx' + yy' + zz' . Orthogonalité : u ⊥ v ⇔ u · v = 0 .
  • Produit vectoriel : u ∧ v = (yz'−zy', zx'−xz', xy'−yx') . Vecteur orthogonal à u et v. Aire du triangle ABC : A = ½ ||AB ∧ AC|| .
  • Produit mixte : (u ∧ v) · w = det(u, v, w) . Coplanarité ⇔ det = 0 . Volume du tétraèdre ABCD : V = (1/6) |(AB ∧ AC) · AD| .
  • Plan P : Équation cartésienne ax + by + cz + d = 0 , de vecteur normal n(a, b, c) .
  • Distance d'un point M0(x0, y0, z0) au plan P :
d(M0, P) = |ax0 + by0 + cz0 + d| / √(a² + b² + c²)
  • Sphère S(I, R) : (x−xI)² + (y−yI)² + (z−zI)² = R² . Intersection Plan/Sphère : si d(I, P) < R , c'est un cercle de centre H (projeté de I sur P) et de rayon r = √(R² − d²) .

Probabilités

  • Formules de base : p(A ∪ B) = p(A) + p(B) − p(A ∩ B) ; p(!A) = 1 − p(A) .
  • Probabilité conditionnelle : p(B | A) = p(A ∩ B) / p(A) . Indépendance : p(A ∩ B) = p(A) · p(B) .
  • Formule des probabilités totales : p(B) = p(A) · p(B|A) + p(!A) · p(B|!A) (utiliser un arbre pondéré !).
  • Variable aléatoire discrète X :
Espérance : E(X) = Σ xi pi | Variance : V(X) = Σ xi² pi − [E(X)]² | Écart-type : σ(X) = √V(X)

  • Loi Binomiale B(n, p) : Répétition de n épreuves indépendantes (succès p ) : p(X = k) = Cn (1−p)n−k ; E(X) = n · p ; V(X) = n · p · (1−p) .
  • Lois continues :
  • Loi uniforme sur [a, b] : densité f(x) = 1/(b−a) ; p(c ≤ X ≤ d) = (d−c)/(b−a) ; E(X) = (a+b)/ 2 .
  • Loi exponentielle de paramètre λ > 0 : p(X ≤ t) = 1 − e−λt ; p(X > t) = e−λt ; E(X) = 1/λ ; sans mémoire : p(X > t+h | X > t) = p(X > h) .
