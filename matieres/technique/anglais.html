Essential Grammar Rules

  • Tenses : Present Simple (habits/facts), Present Continuous (now), Past Simple (finished past + date: ago, yesterday, in 2020), Present Perfect (since, for, already, yet, ever), Past Perfect (action before another past action: had + PP ).
  • Passive Voice : be (in the original tense) + Past Participle . Ex: They built the bridge → The bridge was built.
  • Reported Speech : Backshift tenses (Present → Past, Past → Past Perfect, will → would, can → could). Time markers: today → that day, tomorrow → the next day, yesterday → the day before.
  • Conditionals :
  • Type 1 (Real) : If + Present Simple, will + bare inf.
  • Type 2 (Unreal present) : If + Past Simple, would + bare inf.
  • Type 3 (Past regret) : If + Past Perfect, would have + PP .
  • Linkers : Contrast (However, Although, Despite + noun/V-ing, Whereas) | Cause (Because, Since, Due to + noun) | Consequence (Therefore, Consequently, As a result) | Addition (Moreover, Furthermore, In addition).

Writing Guide (Guided & Free Writing)

  • Guided Writing (4-5 pts) : Respect all notes in the table/chart, use appropriate tense (past for biographies, present for charts/facts), link sentences smoothly.
  • Free Writing (Essay / Article / Formal Letter) :
  • Introduction : General hook + reformulate the issue + thesis statement.
  • Body (2 paragraphs) : Topic sentence + explanation + concrete example. Use linkers (Firstly, Moreover, On the other hand).
  • Conclusion : Summarize main points + final recommendation or personal opinion (To sum up, In a nutshell).
