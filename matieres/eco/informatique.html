Bases de Données & SQL

  • Concepts : Table, Champ, Enregistrement, Clé primaire (PK), Clé étrangère (FK), Relation (1-à-plusieurs) avec intégrité référentielle.
  • Requêtes SQL types Bac Éco :
SELECT nom, salaire FROM Employe WHERE service = 'Vente' ORDER BY salaire DESC; SELECT service, AVG(salaire), COUNT(*) FROM Employe GROUP BY service; SELECT c.nom, SUM(f.montant) FROM Client c, Facture f WHERE c.idC = f.idC GROUP BY c.nom HAVING SUM(f.montant) > 5000; INSERT INTO Client VALUES (12, 'Sami', 'Tunis'); UPDATE Produit SET prix = prix * 1.1 WHERE categorie = 'Info'; DELETE FROM Commande WHERE statut = 'Annulee';
