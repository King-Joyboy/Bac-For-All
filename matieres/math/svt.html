🧬 SVT

4ème Mathématiques (Tunisie) • Reproduction, Génétique, Neurophysiologie & Immunité

Reproduction Humaine

  • Homme : Spermatogenèse dans les tubes séminifères (FSH + Sertoli). Testostérone sécrétée par les cellules de Leydig (LH). Rétrocontrôle négatif (RC−) sur le complexe hypothalamo-hypophysaire (HH).
  • Femme (Cycle 28 j) : Phase folliculaire (FSH, œstradiol : RC− puis RC+ → pic de LH à J14 = ovulation) → Phase lutéinique (corps jaune sécrète progestérone + œstradiol, RC−, préparation de l'endomètre).
  • Fécondation : Tiers supérieur de la trompe ; l'embryon sécrète la HCG qui maintient le corps jaune.

Génétique (Méiose, Brassage & Génétique Humaine)

  • Brassage : Intrachromosomique (crossing-over en prophase I) et interchromosomique (anaphase I).
  • Arbres généalogiques :
  • Parents sains → enfant atteint : allèle récessif. Parents atteints → enfant sain : allèle dominant.
  • Lié à X récessif : Fille atteinte ⇒ père atteint ; mère atteinte ⇒ tous les garçons atteints.
  • Lié à X dominant : Père atteint ⇒ toutes les filles atteintes ; garçon atteint ⇒ mère atteinte.

Neurophysiologie & Immunité

  • Message nerveux : Potentiel de repos (−70 mV, pompe Na+/K+). Potentiel d'action (loi du tout ou rien : dépolarisation par entrée Na+, repolarisation par sortie K+).
  • Synapses : Excitatrice (PPSE, ex : Ach) / Inhibitrice (PPSI, ex : GABA). Sommations spatiale et temporelle.
  • Immunité spécifique : Macrophage (CPA, IL-1) → LT4 (LTa, IL-2) → RIMH (LB → plasmocytes → anticorps) et RIMC (LT8 → LTc → perforine, lyse cellulaire).
  • Dysfonctionnements : Allergie (IgE + mastocytes → histamine) ; SIDA (VIH détruit les LT4 → immunodéficience).
