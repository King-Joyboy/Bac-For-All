Essential Grammar Rules

  • Tenses : Present Simple, Present Continuous, Past Simple, Present Perfect (since, for, already, yet), Past Perfect ( had + PP ).
  • Passive Voice : be (in original tense) + Past Participle .
  • Reported Speech : Backshift tenses (Present → Past, Past → Past Perfect, will → would, can → could).
  • Conditionals : Type 1 ( If + Present, will + V ), Type 2 ( If + Past Simple, would + V ), Type 3 ( If + Past Perfect, would have + PP ).
  • Linkers : Contrast (However, Although, Despite + noun/V-ing) | Cause (Because, Since, Due to) | Consequence (Therefore, Consequently) | Addition (Moreover, Furthermore).

Writing Guide (Guided & Free Writing)

  • Guided Writing : Use all notes accurately, keep tense consistent, connect ideas smoothly.
  • Free Writing : Introduction (hook + thesis) → 2 Body paragraphs (topic sentence + explanation + concrete example + linkers) → Conclusion (summary + personal opinion).
