🎲 Mathématiques : Complexes, Espace & Proba

4ème Sciences Expérimentales (Tunisie) • Complexes, Espace, Probabilités & Statistiques

Nombres Complexes

  • Module & Argument : Pour z = a + ib , |z| = √(a² + b²) , z = r(cos θ + i sin θ) = r eiθ .
  • Moivre & Euler : (eiθ)n = einθ ; cos θ = (eiθ + e−iθ)/2 ; sin θ = (eiθ − e−iθ)/(2i) .
  • Équation az² + bz + c = 0 : Δ = b² − 4ac = δ² ⇒ z1,2 = (−b ± δ)/(2a) .
  • Racines n-ièmes de Z = r eiα : zk = r1/n ei(α + 2kπ)/n ( k = 0, ..., n−1 ).
  • Géométrie complexe : AB = |zB − zA| ; (AB, AC) ≡ arg((zC−zA)/(zB−zA)) [2π] . Alignement ⇔ rapport ∈ ℝ ; Orthogonalité ⇔ rapport ∈ iℝ*.

Géométrie dans l'Espace

  • Produit scalaire : u · v = xx' + yy' + zz' ( 0 si orthogonaux).
  • Produit vectoriel : u ∧ v = (yz'−zy', zx'−xz', xy'−yx') . Aire(ABC) = ½ ||AB ∧ AC|| .
  • Produit mixte : (u ∧ v) · w = det(u, v, w) . Volume tétraèdre ABCD = (1/6) |(AB ∧ AC) · AD| .
  • Plan P (ax + by + cz + d = 0) : Vecteur normal n(a, b, c) . Distance d'un point M0 à P :
d(M0, P) = |ax0 + by0 + cz0 + d| / √(a² + b² + c²)
  • Sphère S(I, R) : (x−xI)² + (y−yI)² + (z−zI)² = R² . Section par un plan P (si d < R ) : cercle de rayon r = √(R² − d²) .

Probabilités & Statistiques

  • Conditionnelle & Probabilités totales : p(B | A) = p(A ∩ B) / p(A) ; p(B) = p(A)p(B|A) + p(! A)p(B|!A) .
  • Variable aléatoire discrète : E(X) = Σ xi pi ; V(X) = Σ xi² pi − [E(X)]² ; σ(X) = √V(X) .
  • k pk (1−p)n−k ; E(X) = np ; V(X) = np(1−p) .
  • Loi Binomiale B(n, p) : p(X = k) = Cn
  • Lois continues : Uniforme sur [a, b] ( E = (a+b)/2 ) ; Exponentielle (λ) : p(X ≤ t) = 1 − e−λt , p(X > t) = e−λt , E = 1/λ .
  • Statistiques à 2 variables : Cov(X, Y) = (1/N)Σ xi yi − x̄ ȳ ; r = Cov(X, Y)/(σX σY) ; Droite de régression : y = ax + b avec a = Cov(X, Y)/V(X) et b = ȳ − a x̄ .
