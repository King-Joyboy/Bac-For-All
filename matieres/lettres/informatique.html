Bases de Données & SQL

  • Modèle relationnel : Table, Champ, Enregistrement, Clé primaire (PK), Clé étrangère (FK), relation 1-à-plusieurs.
  • Requêtes SQL de base :
SELECT titre, auteur FROM Livre WHERE annee >= 2000 ORDER BY titre ASC; SELECT categorie, COUNT(*) FROM Livre GROUP BY categorie; INSERT INTO Auteur VALUES (5, 'Mahmoud Messadi', 'Tunisie'); UPDATE Livre SET prix = 18.5 WHERE idL = 10; DELETE FROM Livre WHERE idL = 10;

Web (HTML5 / CSS3) & Bases de Python

  • HTML5 : Balises de structure ( <html> , <head> , <body> , <h1> , <p> , <a href="..."> , <img src="..."> , <table> , <form> ).
  • CSS3 : Sélecteurs (balise, .classe , #id ), propriétés ( color , background-color , font-size , margin , padding ).
  • Python : Variables, input() , print() , if / elif / else , boucles for et while , fonctions def .
