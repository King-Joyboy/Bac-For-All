Essential Grammar Rules

  • Tenses : Present Simple/Continuous, Past Simple (finished + date), Present Perfect (since, for, already, yet, ever), Past Perfect ( had + PP ), Future ( will / be going to ).
  • Passive Voice : be (in original tense) + Past Participle .
  • Reported Speech : Backshift tenses (Present → Past, Past → Past Perfect, will → would, can → could).
  • Conditionals & Wishes : Type 1 ( If + Present, will + V ), Type 2 ( If + Past Simple, would + V ), Type 3 ( If + Past Perfect, would have + PP ). I wish + Past Simple (present regret) / I wish + Past Perfect (past regret).
  • Linkers : Contrast (However, Although, Despite + noun/V-ing, Whereas) | Cause (Because, Since, Due to) | Consequence (Therefore, Consequently, Thus) | Addition (Moreover, Furthermore).

Writing Guide (Guided & Free Writing)

  • Guided Writing : Expand all notes accurately, use rich linkers and correct tenses.
  • Free Writing (Essay / Article / Speech / Formal Letter) :
  • Introduction : Engaging hook + context + clear thesis statement.
  • Body (2–3 paragraphs) : Topic sentence + explanation + concrete/cultural example.
  • Conclusion : Restate main points + personal stance / recommendation.
